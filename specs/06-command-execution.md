# F06 · 可控命令执行与代码验证

## 目标与用户结果

Agent 能在用户允许的执行模式中运行测试或构建，并返回真实退出码和结果。

受影响用户：本地使用扣仔的开发者及嵌入方。依赖：F05。当前状态见 [实施状态](status.json)，本文不重复维护状态。

## 范围与非目标

范围：异步进程、工作目录、超时、进程组清理、输出上限、附件、明确的宿主执行模式与授权提示。

非目标：不自动安装依赖、扩大权限或静默切换执行模式；首版不承诺内置跨平台容器沙箱。

## 主流程

授权宿主命令执行 → 记录意图 → 启动进程 → 有界读取 stdout/stderr → 超时/取消清理 → 保存结果并回传。

## 错误与边界

工作目录非法、启动失败、非零退出、超时、取消、输出超限分别标识。子进程仍运行时不得谎称取消已完成。

## 数据、接口与安全约束

execute_host=local 明确表示具备宿主用户权限，不受文件工具路径限制。命令包含 cwd/timeout；结果包含 returncode/stdout/stderr/truncation/artifact。首版支持 macOS/Linux，Windows 另行验证。

## 验收条件

- F06-AC1：修改测试夹具中的 bug 后运行测试，退出码反映真实通过与失败。
- F06-AC2：会持续写大量输出的进程不会造成无界内存增长，结果标记截断。
- F06-AC3：超时会终止整个进程组并等待退出；测试验证子进程也停止。
- F06-AC4：未开启宿主命令权限时默认拒绝；无交互模式不得默认同意。
- F06-AC5：工作目录固定为允许工作区；文档说明 shell 内部仍可访问宿主范围，不能称为工作区沙箱。

验收按每条前置条件建立测试夹具，触发所述事件并断言实际输出、状态及副作用；仅“没有抛异常”不足以通过。正常路径和错误路径至少各有一条集成测试，外部服务另用显式 smoke。

预期影响：tools/execution_host.py、tools/builtin/shell.py、tools/policy.py、session/artifacts.py。

```text

```

测试驱动：先运行因缺失能力而失败的聚焦验收，再实现并通过；提交前运行全量回归及必要打包检查。

## 提交边界

一个功能点完成一次提交，提交信息：

```text
feat(F06): execute and verify commands with bounded lifecycle
```

本次提交需包含实现、测试、必要文档及状态证据；推送后核验远端 HEAD 等于本地提交。未通过验收不提前标记 DONE，不用仅写规格的提交冒充功能完成。修复在提交前合并到同一切片；如已推送后发现缺陷，先报告对提交次数的影响，不改写公开历史。

## 风险、假设与开放项

宿主命令可访问用户文件和网络；必须显式选择并确认此模式，不能用命令字符串黑名单充当安全保证。
